# flutter_hello_world

> **Status: archived.** My first Flutter project, kept as a reference.

The counter app that `flutter create` generates (a title, a number and a button that adds one), used to try the Flutter
toolchain and learn the basics: a `StatelessWidget` ([`MyApp`](./lib/main.dart)), a `StatefulWidget` with `setState`
(`MyHomePage`), and a widget test ([test/widget_test.dart](./test/widget_test.dart)).

## Run it

Install [Flutter](https://docs.flutter.dev/get-started/install), then:

```sh
flutter pub get
flutter run          # pick a device: Chrome, an emulator, or your desktop
flutter test         # the widget test
```
